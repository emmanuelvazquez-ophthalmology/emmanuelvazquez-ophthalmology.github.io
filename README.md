# Sitio personal de oftalmología

Plantilla inicial para publicar una biblioteca educativa en GitHub Pages.

## Estructura incluida

- Inicio: nombre, fotografía y biografía.
- Córnea.
- Queratocono.
- Casos clínicos.
- Dificultad básica, media y avanzada.

## Antes de publicar

1. Abre `index.html` y cambia todas las apariciones de **Tu nombre**.
2. Reemplaza los textos de biografía.
3. Renombra tu fotografía como `foto-perfil.jpg` y colócala dentro de `assets`.
4. Edita los casos ubicados en `cornea/queratocono/casos`.
5. No publiques ningún dato que permita identificar pacientes.

## Publicación

Lee `GUIA_PASO_A_PASO.txt`. Está escrita para realizar todo desde el navegador, sin terminal.
